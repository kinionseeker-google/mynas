# 黑曜石云盘（mynas）使用与安装说明

版本 0.1.8。装在 OpenWrt 路由器上的网盘式文件管理服务，用浏览器管理。

0.1.8 起名字由“私有云盘”改为“黑曜石云盘”，并换了新图标。只是显示的名字变了：安装包、命令和配置文件的名字仍是 `mynas`，从旧版本直接升级即可，设置、账号和文件都保留。

本文件夹的内容：

- `install.sh`：自动选包的安装脚本
- `mynas_0.1.8-1_*.ipk`：用于 OpenWrt 24.10 及更早版本
- `mynas-0.1.8-r1_*.apk`：用于 OpenWrt 25.12 及更新版本
- 文件名末尾的 `aarch64`、`x86_64`、`mipsel`、`mips`、`arm` 是处理器类型


## 一、安装

### 安装前确认

- 路由器运行 OpenWrt，并且能用 SSH 登录（默认用户名 root）。
- 路由器有大约 8 MB 的空闲存储空间用来放程序。
- 建议接一块外接硬盘或 U 盘并先挂载好。不接也能装，但文件只能存在路由器闪存里，空间很小。

### 方法一：用安装脚本（推荐）

在电脑上打开终端（Windows 用 PowerShell），进入本文件夹的上一级目录，把整个文件夹拷到路由器再运行脚本。把 `192.168.1.1` 换成你的路由器地址：

```sh
scp -O -r dist root@192.168.1.1:/tmp/mynas
ssh root@192.168.1.1 sh /tmp/mynas/install.sh
```

脚本会识别处理器和系统版本，自动选择对应的安装包。成功后会显示管理界面的地址。

如果文件夹不叫 `dist`，把命令里的 `dist` 换成实际的文件夹名。也可以用 WinSCP 之类的工具（协议选 SCP）把文件夹上传到路由器的 `/tmp/mynas`，再登录路由器运行 `sh /tmp/mynas/install.sh`。

### 方法二：只装一个包

先在路由器上查看处理器类型和系统版本：

```sh
. /etc/openwrt_release; echo $DISTRIB_ARCH $DISTRIB_RELEASE
```

按第一项的开头选安装包：

- `aarch64` 开头：选 `aarch64`。多数较新的 ARM 路由器、软路由、树莓派 3/4/5。
- `x86_64` 开头：选 `x86_64`。x86 软路由、虚拟机。
- `mipsel` 开头：选 `mipsel`。MT7621、MT7620 等。
- `mips_` 开头：选 `mips`。高通 ath79 等。
- `arm_` 开头：选 `arm`。32 位 ARM，如 IPQ40xx。

把对应的一个文件拷到路由器的 `/tmp`，然后按系统版本安装：

```sh
# OpenWrt 24.10 及更早
opkg install /tmp/mynas_0.1.8-1_aarch64.ipk

# OpenWrt 25.12 及更新（安装包没有签名，所以要加这个参数）
apk add --allow-untrusted /tmp/mynas-0.1.8-r1_aarch64.apk
```

装错处理器类型的包不会启动服务，并会提示换包。按提示卸载后重新安装正确的包即可。

### 安装之后

- 服务已经启动，并且开机自启。
- 管理界面：`http://路由器地址:8580`
- 第一次打开时创建管理员账号，密码至少 8 位。**谁先打开谁创建，装完请马上完成这一步。**
- LuCI 的“服务 → 黑曜石云盘”（英文界面是 Services）里可以修改设置。
- 路由器防火墙默认只允许局域网访问，不需要额外配置。


## 二、路由器上的设置

在 LuCI 的“服务 → 黑曜石云盘”里修改，点“保存并应用”后生效。

- **启用**：关掉后服务停止，开机也不启动。
- **管理界面端口**：默认 8580。
- **文件目录**：管理界面里“全部文件”对应的目录。填硬盘的挂载点（例如 `/mnt/sda1`），就能直接看到硬盘上已有的文件；也可以填其中一个子目录，只管理那个目录。
- **等磁盘挂载后再启动**：文件目录在外接硬盘上时请开启。硬盘没挂载时服务不启动，避免把文件写进路由器闪存；硬盘挂上后自动启动。
- **保留空间**：默认 64 MB。文件目录所在磁盘的剩余空间低于这个值时，拒绝上传和下载。
- **配置目录**：默认 `/etc/mynas`，保存账号、链接、任务记录，体积很小，系统升级时保留。
- **代理内嵌端口范围**：默认 18600-18649，外部链接开启“代理内嵌”时使用。

安装时的默认行为：

- 如果外接硬盘已经挂载在 `/mnt/` 下，文件目录自动设为这块硬盘的挂载点（例如 `/mnt/sda1`），硬盘上已有的文件直接可见，并开启“等磁盘挂载后再启动”。
- 只会选中一块硬盘（一个分区）。有多块硬盘或多个分区时，其余的暂时看不到。
- 如果没有硬盘，文件目录是 `/mnt/mynas`，在路由器闪存上。以后接了硬盘，记得到 LuCI 里改文件目录。

文件目录也可以在管理界面的“设置”里改，效果相同，两边会保持一致。

修改文件目录不会搬动已有的文件。回收站跟着文件目录走，换目录后原来回收站里的文件不再显示。

管理界面左下角会显示当前的文件目录。


## 三、使用

### 登录

- 用安装后创建的管理员账号登录，登录状态保持 7 天。
- 连续输错 5 次密码，需要等 1 分钟再试。
- 服务重启后需要重新登录。
- 右上角依次是：上传、上传列表、深浅色切换、退出登录。

### 文件

- **上传**：点右上角“上传”，或把文件拖到页面中间。文件传到当前打开的文件夹；同名文件不会被覆盖，新文件名后面会加上 (1)。
- **浏览**：点文件夹进入，点上方的路径返回上级。右上角可以切换网格和列表两种显示方式。
- **预览**：点图片、视频或音频，会全屏打开预览。用屏幕两侧的箭头或键盘左右键切换上一个、下一个，手机上可以左右滑动；右上角可以下载，按 Esc 或点空白处关闭。浏览器不支持的格式（例如 HEIC 照片、部分 MKV 视频）会提示下载后查看。
- **详情和操作**：点文档等其他文件，右侧出现详情，可以下载、重命名、删除。图片、视频、音频要看详情或重命名，请点文件左上角的小方框选中它。
- **多选**：鼠标移到文件上，点左上角的小方框。选中后上方出现下载、删除等按钮。
- **搜索**：在顶部搜索框输入文件名的一部分，会搜索全部文件。
- **分类**：左侧的“最近”“图片”“视频”“文档”“音乐”按类型列出所有文件。
- **回收站**：删除的文件先进回收站，可以还原到原来的位置，或彻底删除。回收站里的文件仍然占用空间。
- **回收站自动清除**：默认删除满 30 天后自动彻底删除。在回收站页面右上角可以改成 7、15、30、90 天或“永不”。把时限改短时，已经超过新时限的文件会立即被清除，改之前会提示确认。选中一个文件，右侧详情里能看到它还剩多久。
- 暂不支持下载整个文件夹。

### 扩展：外部链接

把路由器后台、影音库、下载器等其他服务的网址接进来，统一从这里打开。

- **添加**：左侧“扩展” → “添加链接”，填名称和网址（以 `http://` 或 `https://` 开头）。
- **打开方式**：“页面内打开”在管理界面中间显示，“新窗口打开”跳转到对方网站。
- **固定到侧栏**：勾选后链接出现在左侧导航下方，点一下直接打开。
- **检测**：让路由器去访问这个网址，告诉你能不能访问、对方是否允许内嵌。
- **代理内嵌**：有些网站禁止被内嵌，页面内打开会是空白。开启“通过 NAS 代理内嵌”后由路由器转发，就能正常显示。每个开启代理的链接占用一个端口，最多 50 个。
- **忽略证书错误**：只用于使用自签名证书的局域网设备。
- 只代理你信任的服务。

### 离线下载

由路由器直接把文件下载回来，关掉浏览器或电脑也会继续。

- 左侧“离线下载”，粘贴下载链接，每行一个，一次最多 100 个。
- 只支持 `http://` 和 `https://` 的直链，**不支持磁力链接和 BT**。
- “保存到”填的是“全部文件”下的文件夹名，默认是“离线下载”。
- 任务可以暂停、继续、取消、重试。暂停后继续会从断点接着下（需要对方服务器支持）。
- 同时最多下载 3 个，其余排队。
- 路由器重启后，没下完的任务会自动继续。
- “移除记录”只删任务记录，已经下完的文件还在。

### 外部网盘

通过 WebDAV 接入其他网盘，在这里浏览，并把文件存到路由器上。

- 左侧“外部网盘” → “添加网盘”，填名称、WebDAV 地址、账号、密码。可以先点“测试连接”。
- 常见的 WebDAV 地址：
  - 坚果云：`https://dav.jianguoyun.com/dav/`，密码要用在坚果云里生成的“第三方应用密码”
  - Nextcloud：`https://你的域名/remote.php/dav/files/用户名/`
  - AList：`http://地址:5244/dav/`
- 目前是**只读**的：可以浏览、下载，不能往网盘上传或删除。
- **保存到 NAS**：选中文件或文件夹，点“保存到 NAS”，会变成离线下载任务，默认存到“离线下载/网盘名”下。文件夹会连同里面的内容一起保存，一次最多 2000 个文件。
- 百度网盘、阿里云盘等没有 WebDAV 的网盘不能直接接入，可以先用 AList 转成 WebDAV 再接。


### 用 Obsidian 同步（WebDAV）

黑曜石云盘自带一个 WebDAV 服务端，Obsidian 装上支持 WebDAV 的同步插件后，可以把路由器当作云端，手动或自动同步笔记库。下面以社区插件 Remotely Save 为例。

**第一步：在黑曜石云盘里生成访问密码**

1. 左侧点“WebDAV 同步”，记下页面上的服务器地址，形如 `http://路由器地址:8580/dav/`。
2. 点“新建访问密码”。账号默认是 `obsidian`，存放位置默认是独立的同步空间，名称默认是 `Obsidian`，直接点“生成”即可。
3. 页面会显示账号和一串自动生成的密码。**密码只显示这一次**，请马上复制保存。

**第二步：在 Obsidian 里设置**

1. “设置 → 第三方插件”里关闭安全模式，浏览社区插件，搜索并安装 Remotely Save，然后启用。
2. 打开插件设置，远程服务选择 WebDAV。
3. 填入服务器地址、账号和密码，点检查连接。
4. 手动同步：点 Obsidian 左侧边栏的同步图标。
5. 自动同步：在插件设置里打开定时自动运行并选一个间隔。自动同步只在 Obsidian 开着的时候运行。

插件里选项的具体名称以它当前的界面为准。第一次同步前建议先备份笔记库。

**同步空间：和自己的文件分开存放**

同步来的数据默认放在“同步空间”里，不和“全部文件”混在一起：

- 同步空间里的内容不会出现在“全部文件”、“最近”、图片/视频/文档/音乐分类和搜索结果里。
- 在“WebDAV 同步”页面的“同步空间”一栏查看：点“打开”进去，可以像普通文件一样浏览、预览、下载、上传、重命名、删除，搜索框只搜这个空间里的内容。
- 新建访问密码时，“存放位置”默认就是“独立的同步空间”，填一个空间名称即可。多台设备同步同一个笔记库，填同一个名称。
- 也可以把“存放位置”改成“全部文件里的文件夹”，那样同步来的内容会出现在“全部文件”里。
- 已经同步到“全部文件”某个文件夹里的，在它的访问密码卡片上点“移到同步空间”，文件夹会整个移过去。账号和密码不变，Obsidian 那边不用改任何设置。
- 没有访问密码在使用的同步空间可以删除，删除后进回收站。
- 在硬盘上，同步空间位于文件目录下的 `.mynas-sync` 文件夹里，一个空间一个子文件夹，里面是普通文件。

**需要知道的几点**

- 同步软件用的是这里生成的访问密码，不是管理员密码。每个访问密码只能进入指定的一个同步空间或文件夹，看不到其他文件。
- 同步时删除的笔记会进黑曜石云盘的回收站，可以还原，到期后按回收站的设置自动清除。被覆盖的旧内容不会保留。
- 不想让某个设备再同步，在“WebDAV 同步”页面移除它的访问密码，立即失效。
- 访问密码忘了或者怀疑泄露了，在它的卡片上点“重新生成密码”。旧密码立即失效，账号和已经同步的文件不变，把新密码填到同步软件里即可。
- 访问密码可以设为只读：只能下载，不能上传、修改或删除。
- 多台电脑同步同一个笔记库，建议每台各建一个访问密码，同步空间名称填同一个。
- 同步的文件就是普通文件，在“WebDAV 同步”页面打开对应的同步空间就能看到。
- 其他支持 WebDAV 的软件也可以用同样的地址、账号和密码。
- 连接没有加密（HTTP），只在自己可信的局域网里用。电脑不在家时无法同步，回到家里的网络后再同步即可。
- 手机上的 Obsidian 可能不允许连接没有加密的地址，这一点没有验证过。


### 设置：修改管理员用户名和密码

1. 左侧点“设置”，在“管理员账号”里点“修改用户名或密码”。
2. 输入当前密码。要改用户名就改上面的用户名；要改密码就填两次新密码（至少 8 位），不改密码就留空。
3. 点“保存”，立即生效。

- 修改后，其他已经登录的浏览器会被退出，正在操作的这个浏览器保持登录。
- 这里改的是登录管理界面的账号。Obsidian 等同步软件用的是“WebDAV 同步”页面里的访问密码，不受影响，也不在这里改。
- 当前密码连续输错 5 次，同样需要等 1 分钟。
- 当前密码想不起来了，看后面“常见问题”里的“忘记管理员密码”。

### 设置：更改存储位置

存储位置就是“全部文件”、回收站和同步空间实际存放的文件夹，可以在管理界面里直接改。

1. 左侧点“设置”，在“存储位置”里能看到当前位置和所在磁盘的容量。
2. 点“更改存储位置”。可以直接输入完整路径，也可以在下面的文件夹列表里点选：上面一排是磁盘或挂载点，点文件夹进入下一级，点“上一级”返回。想用一个还不存在的文件夹，就在输入框里接着写它的名字，会自动新建。
3. 输入管理员密码，点“更改”。更改立即生效，不需要重新登录，也不需要重启。

更改前请了解：

- **不会自动搬文件。** 现有的文件、回收站和同步空间留在原位置。需要的话，先自己把它们复制到新位置（包括其中的 `.mynas-sync` 文件夹，那是同步空间）。
- **换回原位置，原来的内容会重新出现**，包括回收站里的东西。
- **同步空间没有一起搬过去时**，Obsidian 等软件会同步失败并报错，不会把笔记当成已删除。在“WebDAV 同步”页面，对应的访问密码会标出“文件夹不存在”。把原来的文件夹复制过来即可恢复；如果确实想从空的开始，再点“新建空文件夹”。
- **有离线下载正在进行或排队时不能更改**，等它们完成或先暂停。
- 不能选系统目录、系统盘的根目录，也不能选包含黑曜石云盘自身配置的文件夹。
- 在路由器上，这里的更改会同步写回 LuCI 的“文件目录”，并自动决定是否“等磁盘挂载后再启动”。两边改哪边都可以。
- 如果启动时上次选的位置用不了（例如硬盘没接上），服务会临时使用默认位置，并在“设置”页面提示。

## 四、升级和卸载

**升级**：和安装一样，装新版本的包即可。设置、账号和文件都会保留，服务自动重启。

**卸载**：

```sh
opkg remove mynas      # OpenWrt 24.10 及更早
apk del mynas          # OpenWrt 25.12 及更新
```

卸载后账号数据（`/etc/mynas`）、设置（`/etc/config/mynas`）和文件目录都会保留。想彻底清除，需要自己删掉这几处。


## 五、常见问题

**管理界面打不开**

到 LuCI 的“服务 → 黑曜石云盘”看运行状态：

- 显示“等待磁盘挂载”：文件目录所在的硬盘没有挂上。检查硬盘，或把文件目录改到别处。
- 显示“未运行”：确认“启用”已勾选，然后保存并应用。
- 显示“运行中”但打不开：确认访问的端口和设置里的一致，并且电脑和路由器在同一个局域网。

也可以登录路由器看日志：`logread -e mynas`

**硬盘已经挂载，容量显示正确，但看不到硬盘上已有的文件**

文件目录指向了硬盘里的一个子目录（0.1.0 版默认是硬盘上的 `mynas` 目录），所以只能看到那个子目录。到 LuCI 的“服务 → 黑曜石云盘”，把“文件目录”改成硬盘的挂载点，例如把 `/mnt/sda1/mynas` 改成 `/mnt/sda1`，保存并应用。之前上传的文件会出现在“全部文件”下的 `mynas` 文件夹里。

**上传或下载提示空间不足**

文件目录所在磁盘的剩余空间低于“保留空间”。清理文件（包括回收站），或把文件目录改到更大的磁盘上。

**忘记管理员密码**

还记得密码、只是想换一个：在管理界面左侧“设置”里点“修改用户名或密码”。

完全想不起来：登录路由器执行下面三行，然后重新打开管理界面创建账号。文件、链接、网盘和任务都不受影响。

```sh
/etc/init.d/mynas stop
sed -i '/^  "admin": {/,/^  },/c\  "admin": null,' /etc/mynas/state.json
/etc/init.d/mynas start
```

**外部链接页面内打开是空白**

点“检测”。如果提示网站禁止内嵌，点“开启代理内嵌”，或者把打开方式改成新窗口。

**常用命令**

```sh
/etc/init.d/mynas restart     # 重启服务
/etc/init.d/mynas stop        # 停止
mynas -version                # 查看版本
logread -e mynas              # 查看日志
```


## 六、安全须知

- 服务使用 HTTP，没有加密。只在自己可信的局域网里使用，不要把端口映射到公网。需要在外面访问时，通过 WireGuard 或 Tailscale 连回家里。
- 只有一个管理员账号，登录后拥有全部权限。
- 外部网盘的密码需要原样使用，以明文保存在路由器的 `/etc/mynas/state.json` 里。建议使用网盘提供的应用专用密码，并给路由器设置登录密码。
- 外部链接的代理端口只对已登录管理界面的浏览器开放。
- WebDAV 访问密码会以明文保存在同步软件（例如 Obsidian 插件）的设置里。它只能进入指定的文件夹，泄露后在“WebDAV 同步”页面移除即可。


## 七、目前的限制

- 没有多用户、权限和分享链接。
- 没有局域网设备发现、共享空间和 SMB 共享。
- 离线下载不支持磁力链接和 BT。
- 外部网盘只读，只支持 WebDAV。
- 不能下载整个文件夹。
- 超过 4 MB 的图片在列表里只显示图标，不显示缩略图；点开预览时加载的是原图。
- 文件很多时，搜索、“最近”和分类会比较慢（每次都要扫描整个文件目录）。
- 只能管理一个文件目录，不能同时管理多块硬盘。
- 安装包只在 x86_64 的 OpenWrt 24.10.8 和 25.12.6 上实际安装测试过。ARM 和 MIPS 的程序只在模拟器里运行过，还没有在真实路由器上验证。
